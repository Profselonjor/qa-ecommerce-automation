# 🛒 QA Automation - E-Commerce System

## 🚀 Overview
End-to-end QA automation project simulating real-world testing of an E-Commerce system.

## 🧪 Scope
- Login API
- Cart API
- Checkout API

## ⚙️ Automation
- Postman + Newman
- CI/CD via GitHub Actions

## 📊 Result
Automation runs on every push and generates report artifact.
